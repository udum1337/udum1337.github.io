# Jelly Stack

Аркада про башню из желе. Написана на JavaScript и Phaser 3, работает в браузере.

## Как играть

Носик ездит над башней. Тап, клик или пробел роняет желешку. Лишняя часть отрывается и падает, башня кренится. Если перекос слишком большой, башня рушится.

Чем выше башня, тем быстрее двигается носик. Рекорд хранится в `localStorage`.

## Запуск

Открой `index.html` в браузере. Если нужен сервер:

```
python -m http.server 8000
```

Дальше открыть `http://localhost:8000`.

## Структура

```
jelly-stack/
├─ index.html       страница и подключение скриптов
├─ game.js          сцены, счёт, камера, управление
├─ jelly.js         мягкое тело на пружинах
├─ drips.js         оторванные куски
├─ sfx.js           звук на WebAudio
├─ phaser.min.js    Phaser 3.90.0
└─ LICENSE-PHASER.txt  лицензия Phaser
```

Phaser распространяется по лицензии MIT, текст лежит в `LICENSE-PHASER.txt`.

## Что внутри

- Физика мягкого тела: сжатие и боковой сдвиг на пружинах.
- Оторванные куски деформируются и падают.
- Процедурный звук без аудиофайлов.
- Рекорд в `localStorage`.
- Управление мышью, тапом и клавиатурой.
- Подгонка под экран телефона.

## Ограничения

- Нет таблицы рекордов и аккаунтов.
- Звук включается после первого касания, как требуют браузеры.
- Игра рассчитана на один экран, без уровней и сохранений.

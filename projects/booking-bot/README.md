# Бот записи для барбершопа

Демо-бот на Python и aiogram 3. Клиент выбирает услугу, день и время, оставляет имя и телефон. Мастер получает уведомление в Telegram, клиенту уходят напоминания за сутки и за два часа.

Салон «Клинок» и имена барберов вымышленные. Это демо для показа механики, а не бот конкретного салона.

## Что умеет

Клиент:

- записывается на услугу, день и время;
- смотрит карточки барберов с опытом, рейтингом и доплатой;
- видит только свободные слоты с учётом длительности услуги;
- отменяет запись в «Мои записи»;
- получает напоминания за 24 часа и за 2 часа.

Владелец и барберы:

- владелец видит все записи, барбер только свои;
- добавляет услуги, барберов и выходные;
- меняет название, длительность, цену и доплату;
- получает уведомление о новой записи или отмене;
- настраивает уведомления для каждого сотрудника.

## Запуск

1. Создай бота у @BotFather и скопируй токен.
2. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN` и `ADMIN_IDS`.
3. Поставь зависимости:

   ```
   python -m venv .venv
   .venv\Scripts\pip.exe install -r requirements.txt
   ```

4. Запусти `run.bat` или `.venv\Scripts\python.exe bot.py`.
5. Отправь боту `/start`, проверь запись и открой `/admin`.

Свой Telegram ID можно узнать командой `/myid`. База `booking.db` создастся при первом запуске. Чтобы сбросить демо-данные, удали файл и запусти бота снова.

## Прокси

Если Telegram API недоступен напрямую, укажи `PROXY_URL` в `.env`. Бот проверит порты 10809, 10801, 7890, 10808, 7891 и 1080 и подключится через первый рабочий.

## Настройка под клиента

- `config.py`: название, адрес, телефон, часы работы, шаг слотов, услуги.
- `texts.py`: все тексты и формулировки.
- `.env`: токен, `ADMIN_IDS`, прокси.
- `avatar.png`: аватарка бота.

После правок перезапусти бота. Если менял услуги в `config.py`, удали `booking.db`, чтобы демо-данные засеялись заново.

## Структура

```
booking-bot/
├─ bot.py            запуск и подключение
├─ config.py         настройки бизнеса и услуг
├─ texts.py          тексты бота
├─ keyboards.py      кнопки
├─ db.py             SQLite
├─ slots.py          расчёт свободного времени
├─ client.py         клиентский сценарий
├─ admin.py          записи, услуги, выходные
├─ barbers.py        барберы и уведомления
├─ notifications.py  сообщения владельцу и барберу
├─ reminders.py      напоминания
├─ make_avatar.py    генератор аватарки
├─ requirements.txt
└─ run.bat
```

## Ограничения

- Один салон на бота. Для нескольких точек нужны отдельные боты или доработка.
- Деньги бот не принимает. Оплата на месте.
- Форма записи живёт в памяти. Если бот перезапустится, начатая заявка сбросится.
- Интеграции с CRM нет.
- SQLite подходит для одного салона. Для сети нужен PostgreSQL.

## Приватность

В репозитории нет `.env`, базы и логов. Телефоны клиентов хранятся только в локальной SQLite.

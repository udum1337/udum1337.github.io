# Бот-визитка на aiogram 3

Шаблон Telegram-бота для фрилансера или небольшой студии. Меню, форма заявки и отзывы с проверкой.

## Что умеет

- `/start`: приветствие и меню.
- Кнопки «Обо мне», «Опыт», «Чем могу помочь», «Портфолио», «Отзывы», «Связаться».
- «Оставить заявку»: имя, задача, контакт. Заявка приходит владельцу в Telegram.
- «Отзывы»: посетитель ставит оценку от 1 до 5 и пишет пару слов. Отзыв появляется после подтверждения владельцем.
- `/reviews`: отзывы на проверке, только для владельца.
- `/myid`: узнать свой Telegram ID.
- `/cancel`: выйти из формы.
- На любой другой текст бот отвечает подсказкой.

## Запуск

1. Создай бота у @BotFather и скопируй токен.
2. Скопируй `.env.example` в `.env` и вставь токен в `BOT_TOKEN`.
3. Поставь зависимости:

   ```
   python -m venv .venv
   .venv\Scripts\pip.exe install -r requirements.txt
   ```

4. Запусти `run.bat` или `.venv\Scripts\python.exe bot.py`.
5. Отправь боту `/myid` и впиши число в `OWNER_ID` в `.env`.
6. Перезапусти бота и напиши `/start`.

Если Telegram API недоступен напрямую, укажи `PROXY_URL` в `.env`. Бот проверит порты 10809, 10801, 7890, 10808, 7891 и 1080 и подключится через первый рабочий.

## Что менять

Все тексты, ссылки и контакты лежат в `texts.py`. В шаблоне стоит заглушка `@your_username`, замени её на свой контакт.

- `START_TEXT`: приветствие.
- `MENU`: кнопки главного меню.
- `SECTIONS`: тексты разделов.
- `SECTION_LINKS`: кнопки-ссылки под разделами.
- `SECTION_BUTTONS`: кнопки под разделами.
- `ORDER_*`: тексты формы заявки.
- `ORDER_SUMMARY`: сообщение, которое получает владелец.
- `REVIEWS_*`: тексты отзывов.
- `REVIEWS_PER_PAGE`: сколько отзывов на странице.

После правок перезапусти бота.

## Отзывы

Отзывы лежат в `reviews.json` рядом с ботом. Файл создаётся сам. Отзыв попадает в список на проверку, владелец открывает `/reviews` и публикует или отклоняет его.

Чтобы удалить отзыв, открой `reviews.json` и удали элемент из `items`. Перед правкой останови бота.

## Аватарка

`avatar.png` уже готов. Перегенерировать или поменять цвета:

```
.venv\Scripts\python.exe make_avatar.py
```

Цвета градиента лежат в списке `STOPS` внутри `make_avatar.py`.

## Ограничения

- Один владелец на бота.
- Отзывы хранятся в JSON. Для большого потока лучше база.
- Оплаты нет, бот принимает только заявки.
- Нет интеграции с CRM.

## Приватность

В репозитории нет `.env`, логов и настоящих контактов. Токен и ID владельца задаются локально.
